# 🚗 NurPoput KG — Сервис попутчиков и доставки посылок по Кыргызстану

Современный, быстрый и полностью автономный сервис поиска попутчиков и передачи посылок между городами Кыргызстана (Бишкек, Ош, Каракол, Нарын, Талас, Баткен, Джалал-Абад и др.).

Проект разработан без сторонних тяжёлых фреймворков (чистый HTML5, CSS3, Vanilla JavaScript) и **полностью автономен** — он не зависит от Netlify или сторонних облачных блокировок.

---

## ⚡ Способы запуска проекта

### 1. Быстрый запуск в 1 клик на Windows
Просто дважды кликните по файлу:
👉 **`Запуск_NurPoput.bat`** (или **`start.bat`**)
* Проект запустит встроенный локальный сервер и автоматически откроет страницу в браузере по адресу: **http://localhost:3000**

---

### 2. Запуск через Visual Studio Code
1. Откройте папку проекта в **Visual Studio Code** (`Файл` -> `Открыть папку`).
2. **Способ А (Встроенный отладчик):** Нажмите клавишу `F5` или перейдите во вкладку `Запуск и отладка` (Run and Debug) и нажмите зелёную стрелку **«Запустить NurPoput (Node.js Server)»**.
3. **Способ Б (Через терминал VS Code):**
   * Откройте терминал (`Ctrl + ~` или `Терминал` -> `Создать терминал`).
   * Введите команду:
     ```bash
     npm start
     ```
   * Перейдите по адресу: [http://localhost:3000](http://localhost:3000)
4. **Способ В (Без Node.js через расширение Live Server):**
   * Установите расширение **Live Server** в VS Code.
   * Кликните правой кнопкой мыши по `index.html` -> выберите **«Open with Live Server»**.

---

### 3. Запуск через командную строку (Terminal / PowerShell / CMD)
```bash
node server.js
```
Сервер будет доступен по адресу: `http://localhost:3000`.

## 🌐 Публикация на любом хостинге (БЕЗ Netlify)

Проект содержит все необходимые конфигурационные файлы для развёртывания на любой платформе:

### Вариант 1: Vercel (Бесплатно, рекомендуется)
1. Зарегистрируйтесь на [vercel.com](https://vercel.com) (через GitHub или Google).
2. Нажмите **«Add New Project»** и выберите ваш репозиторий с проектом (или перетащите папку проекта в десктопное приложение / используйте команду `npx vercel`).
3. Файл конфигурации `vercel.json` уже настроен в проекте. Сайт заработает мгновенно с бесплатным SSL-сертификатом.

### Вариант 2: Surge.sh (Мгновенно из консоли)
В папке проекта выполните команду:
```bash
npx surge . your-subdomain.surge.sh
```
Файлы `200.html` и `.surgeignore` уже подготовлены для корректной маршрутизации SPA.

### Вариант 3: GitHub Pages (Бесплатно)
1. Загрузите файлы в репозиторий на GitHub.
2. В настройках репозитория откройте раздел **Settings** -> **Pages**.
3. В графе **Branch** выберите `main` (или `master`) и папку `/ (root)`, нажмите **Save**.
4. Файл `404.html` уже настроен в проекте для работы всех внутренних страниц.

### Вариант 4: Обычный хостинг / cPanel / Apache (Beget, Timeweb, Reg.ru и др.)
1. Загрузите все файлы проекта в корневую папку сайта (`public_html` или `www`).
2. Файл `.htaccess` уже создан в проекте и автоматически настроит перенаправление всех запросов на `index.html`.

### Вариант 5: Свой сервер VPS / Ubuntu / Nginx
1. Скопируйте файлы проекта в `/var/www/nurpoput`.
2. Готовый пример конфигурации виртуального хоста находится в файле `nginx.conf`.
3. Либо запустите Node.js сервер через менеджер процессов `pm2`:
   ```bash
   pm2 start server.js --name nurpoput
   ```

## 📁 Структура проекта

* `index.html` — главная страница приложения (все экраны и модальные окна SPA).
* `script.js` — логика приложения, авторизация, поиск поездок, чаты, баланс, автономная база данных `LocalDB`.
* `style.css` — стили и адаптивный дизайн для смартфонов, планшетов и ПК.
* `server.js` — локальный сервер на чистом Node.js (без зависимостей) с API синхронизации.
* `manifest.json` и `sw.js` — манифест и Service Worker для работы как PWA (установка как приложение на телефон).
* `vercel.json` — конфигурация для хостинга Vercel.
* `.htaccess` — конфигурация для серверов Apache / cPanel.
* `nginx.conf` — пример конфигурации для Nginx / VPS.
* `200.html` и `404.html` — файлы для корректной маршрутизации SPA на статических хостингах.
* `.vscode/` — настройки для запуска и отладки проекта в Visual Studio Code.
* `data/store.json` — локальное файловое хранилище данных при работе через `server.js`.
