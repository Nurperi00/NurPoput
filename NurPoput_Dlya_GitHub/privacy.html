Политика конфиденциальности сервиса NurPoput

Дата обновления: 3 ноября 2026 г.

1. Общие положения

Сервис NurPoput (далее — «Сервис») предоставляет платформу для поиска попутчиков, совместных поездок по Кыргызстану и доставки малогабаритных посылок. Мы уважаем конфиденциальность пользователей и стремимся защищать их личные данные.

2. Какие данные мы собираем

  • Имя и контактный номер телефона для связи между водителями и пассажирами.
  • Параметры поездки (маршрут отправления и прибытия, дата, время, количество мест, класс и гос. номер автомобиля).
  • Данные о посылках (описание груза, телефоны отправителя и получателя).

3. Как используются данные

  • Для организации связи между водителем и пассажиром/отправителем.
  • Для показа подходящих поездок в результатах поиска.
  • Для уведомления пассажира о появлении подходящей машины по его заявке.

4. Защита данных

Мы не продаем и не передаем персональные данные третьим лицам в маркетинговых целях. Все данные передаются по защищенному протоколу HTTPS.

5. Контакты

По всем вопросам работы сервиса NurPoput вы можете обращаться через службу поддержки на сайте: nurpoput-kg.surge.sh.
