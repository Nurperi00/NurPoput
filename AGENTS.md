# AGENTS.md

## Архитектура

NurPoput — сервис поиска попутчиков по Кыргызстану. Статический фронтенд
(корень репозитория) общается с Netlify Functions в `netlify/functions/`.
Данные хранятся в Netlify Database (Postgres) через Drizzle ORM
(`db/schema.ts`, клиент в `db/index.ts`).

- Аутентификация: собственные сессии. Пароли — scrypt с солью
  (`netlify/functions/lib/auth.ts`). Сессия — HttpOnly cookie
  `nurpoput_session`, таблица `sessions` с истечением через 30 дней.
- Первый зарегистрированный пользователь автоматически получает роль
  `admin` (см. `netlify/functions/auth.ts`). Панель `/api/admin`
  проверяет роль на сервере.
- Бронирование уменьшает количество свободных мест атомарно
  (SQL-выражение `seats - n`), дубли и свои поездки заблокированы.

## Ключевые каталоги

- `netlify/functions/` — API-эндпоинты (`Config.path` задаёт маршрут)
- `netlify/database/migrations/` — SQL-миграции, применяются платформой
  при деплое. Не применять вручную.
- `db/` — схема и клиент Drizzle

## Конвенции

- TypeScript для функций, strict-режим, ESM-импорты с расширением `.js`.
- После изменения схемы: `npx drizzle-kit generate --name <slug>` —
  и никогда не редактировать уже применённые миграции.
- Пользовательские тексты в интерфейсе — на русском языке.
- Города Кыргызстана продублированы в `script.js` и в функциях
  (`CITIES`); при изменении списка правь оба места.
- Не добавлять секреты в код; соединение с БД конфигурируется платформой.
